# TV P3ND iOS

تطبيق iOS مبني بـ SwiftUI و WKWebView لفتح https://tv.p3nd.fun/ داخل التطبيق.

## الميزات

- رسالة ترحيبية عند التشغيل الأول.
- رجوع، التالي، الرئيسية، وإغلاق المشغل.
- دعم الوضع الأفقي وملء الشاشة.
- الروابط الداخلية تبقى داخل التطبيق، والخارجية تُفتح في Safari.
- GitHub Actions ينشئ IPA غير موقّع كـ Artifact عند كل دفع إلى main.

## التوقيع

لإنشاء IPA قابل للتثبيت، افتح المشروع في Xcode، اختر فريق Apple Developer، ثم Archive وDistribute App.
